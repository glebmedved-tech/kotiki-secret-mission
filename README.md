# Котики: Тайная миссия

Рабочая версия игры 5.6.2 на GitHub Pages. Локальные режимы: статические HTML/JS. Комнаты: отдельный сервер, общая прогулка, чат и предметы. Ожидаемый адрес: https://glebmedved-tech.github.io/kotiki-secret-mission/ .

Сохранения остаются в localStorage браузера. Между доменами автоматически не переносятся. Обновление 5.6.2: собственный сервер комнат и упрощённое соединение, проверенное на iPad Даши. Возможности 5.6.1: явная кнопка создания кода из четырёх цифр, удобное приглашение друзей, обновлённые котики и объекты на картах с облегчённой графикой. Возможности 5.6: спокойная карта, четыре обновляемые викторины, комнаты на 2–6 человек с кодом и одобрением, новая обложка и оформление. Сохранены 40 моделей оружия (20 пистолетов и 20 ножей), карты Котокафе/Аквапарк/Кинотеатр, обувь, предметы и эмоции, помощь Чатика из наблюдения. Воскрешение действует в активном обычном раунде; правила дуэлей и тренировок сохранены.

Страница save-transfer.html экспортирует/импортирует JSON вручную, только после действий пользователя. Перед заменой импорт сохраняет предыдущий JSON в catsSecretSave_importBackup.

Проверка в браузере на компьютере не подтверждает работоспособность на реальном iPad.
