# Котики: Тайная миссия

Рабочая версия игры 5.5.1 на GitHub Pages. Статические HTML/JS, без серверного движка. Ожидаемый адрес: https://glebmedved-tech.github.io/kotiki-secret-mission/ .

Сохранения остаются в localStorage браузера. Между доменами автоматически не переносятся. Новые возможности: 40 моделей оружия (20 пистолетов и 20 ножей), карты Котокафе/Аквапарк/Кинотеатр, обувь, предметы и эмоции, помощь Чатика из наблюдения. Воскрешение действует в активном обычном раунде; правила дуэлей и тренировок сохранены.

Страница save-transfer.html экспортирует/импортирует JSON вручную, только после действий пользователя. Перед заменой импорт сохраняет предыдущий JSON в catsSecretSave_importBackup.

Проверка в браузере на компьютере не подтверждает работоспособность на реальном iPad.
